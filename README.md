# YanLan

Неофициальный лаунчер Yandere Simulator для Windows: отдельные сборки игры, установка модов и редактирование их конфигов.

![version](https://img.shields.io/badge/version-1.9.5-ff4d8d) ![license](https://img.shields.io/badge/license-CC%20BY--NC%204.0-lightgrey)

## Возможности

- Независимые сборки в `games/<название>`. Версии игры 2014–2026 берутся с официального сайта и зеркал archive.org.
- Установка ZIP, RAR и 7z в выбранную сборку. Заменённые файлы резервируются и восстанавливаются при удалении мода.
- Каталог YanMod: поиск, совместимость со сборкой, несколько версий одного мода, скриншоты (включая анимированные GIF) и встроенный плеер YouTube.
- Редактор конфигов установленных модов: `BepInEx/*.cfg`, `AutoTranslator/Config.ini` и другие INI-файлы. `true`/`false` показываются переключателями, значения из `Acceptable values` — списком; комментарии и порядок строк сохраняются.
- Русский и английский интерфейс, тёмная и светлая темы.
- Повтор загрузки при обрыве сети, прогресс, журнал действий.

## Каталог YanMod

Источник — репозиторий [`bylka882-png/YanMod`](https://github.com/bylka882-png/YanMod). Мод — это папка с `info.yaml`; скриншоты `.webp`/`.gif` лежат рядом. Список файлов берётся из `index.yaml`, иначе из GitHub Tree API, при исчерпании лимита — из jsDelivr. Кэш каталога живёт 6 часов.

Поля манифеста:

| Поле | Назначение |
| --- | --- |
| `id`, `name`, `by`, `credits` | Идентификатор, название, автор и ссылки; варианты с одним `id` собираются в одну карточку |
| `v` | Версия мода |
| `gameV` | Совместимость: `U19`, `>=U17`, `<=U20`, `2019.07.01`, период `2017.10.04-2019.07.01` или `own` |
| `DL_url` | Ссылка на архив; пустое значение — карточка «Скоро» |
| `type` | `PM`, `Build`, `TR`, `ML`, `Mod`, `Plugin`, `Translate`; можно не заполнять — тип берётся из папки |
| `cfg` | Путь к конфигу от папки сборки, например `BepInEx\config\BepInEx.cfg` |
| `dependencies` | `id` модов, которые нужно установить вместе |
| `affected_files` | Файлы, которые заменяет мод |

## Данные

Корневой каталог задаётся при первом запуске (по умолчанию `%LOCALAPPDATA%\YanLan`):

```
YanLan/
├─ games/          сборки; в каждой лежит .yanlan.json
├─ downloads/      скачанные архивы, если включено их сохранение
├─ cache/          каталог версий и модов, обложки
└─ library.json    установленные моды
```

Настройки лаунчера хранятся в `%APPDATA%\YanLan\config.json`.

## Сборка

Нужны Rust 1.85+ с toolchain MSVC и WebView2 Runtime (входит в Windows 10/11).

```powershell
cargo build --release
```

Готовый файл — `target\release\yanlan.exe`. RAR читается через `unrar`, 7z — через `zesven`, ZIP — через `zip`; внешние DLL не нужны.
