# YanLan
<img width="1224" height="640" alt="1104" src="https://github.com/user-attachments/assets/c11640a2-790e-4fef-ba29-78507e4bb560" />

Неофициальный лаунчер **Yandere Simulator** для Windows. Помогает держать несколько независимых сборок игры, ставить в них моды и откатывать изменения.

![version](https://img.shields.io/badge/version-1.3.0-ff4d8d) ![license](https://img.shields.io/badge/license-CC%20BY--NC%204.0-lightgrey)

## Возможности

- **Сборки** — каждая сборка это отдельная папка `games/<название>` со своими модами. Создать сборку можно из любой версии игры 2014–2026 (список версий берётся с официального сайта и зеркал archive.org).
- **Играть можно всегда** — пока одна сборка скачивается и распаковывается, уже установленные запускаются как обычно.
- **Сортировка** — по версии, по размеру или по имени; выбор сохраняется в конфиге.
- **Переименование** — у сборок без названия есть кнопка «✎ Имя». Меняется только подпись, папка на диске остаётся прежней.
- **Моды** — установка архива в выбранную сборку с автоматическим резервным копированием заменённых файлов и полным откатом при удалении мода.
- **Форматы архивов** — ZIP, RAR и 7z (7z распаковывается на чистом Rust через `zesven`).
- **Два языка** — русский и английский, переключаются в настройках и применяются сразу.
- **Темы** — тёмная и светлая, включая оформление системного заголовка окна.
- **Уведомления и журнал** — все действия видны в тостах и в журнале настроек.

## Вкладки

| Вкладка | Что делает |
| --- | --- |
| **Сборки** | Список установленных сборок, создание, выбор активной, папка, удаление |
| **Каталог** | Заглушка под будущий каталог модов, патчей и текстур |
| **Установлено** | Моды, установленные в каждую сборку; установка архива вручную и удаление |
| **Настройки** | Язык, корневой каталог, тема, поведение, обновление каталога, журнал |

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl+N` | Открыть окно создания сборки |
| `Enter` | Подтвердить создание сборки / сохранение имени |
| `Esc` | Закрыть диалог |

## Данные

Корневой каталог задаётся в настройках (по умолчанию `%LOCALAPPDATA%\YanLan`):

```
YanLan/
├─ games/          сборки; в каждой лежит .yanlan.json с названием и версией
├─ downloads/      скачанные архивы (если включено «Оставлять архивы»)
├─ cache/          кэш каталога версий
└─ library.json    список установленных модов
```

Конфигурация хранится отдельно: `%APPDATA%\YanLan\config.json`.

## Сборка из исходников

Нужен Rust 1.85+ (проверено на 1.99) и MSVC toolchain.

```powershell
cargo build --release
```

Готовый файл: `target\release\yanlan.exe`. Иконка и метаданные встраиваются `build.rs` через `winresource`.

Зависимости подобраны так, чтобы не требовать внешних DLL: RAR читается `unrar`, 7z — `zesven`, ZIP — `zip`.

## Оформление

Интерфейс использует **Comic Sans MS** (`C:\Windows\Fonts\comic.ttf`). Если шрифт недоступен, egui берёт встроенный — лаунчер всё равно запустится.
