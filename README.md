# YanLan

Неофициальный лаунчер Yandere Simulator для Windows: отдельные сборки игры, каталог модов и редактор их конфигов.

## Возможности

- Независимые сборки в `games/<название>`: версии игры 2014–2026 с официального сайта и зеркал archive.org, своя папка, моды и настройки у каждой.
- Установка ZIP, RAR и 7z, включая многотомные архивы. Заменённые файлы резервируются и восстанавливаются при удалении мода.
- Каталог YanMod: поиск, фильтры, совместимость с выбранной сборкой, несколько версий одного мода, скриншоты и GIF, встроенный плеер YouTube.
- Зависимости модов: установка по одной или сразу со всем списком; состав готовой сборки (`ioa`) виден в её карточке.
- Редактор конфигов: визуальный и текстовый режимы, поиск по параметрам, переключатели, списки, цвета и захват клавиш. Комментарии и порядок строк сохраняются.
- Русский и английский интерфейс, тёмная и светлая темы, прокси HTTP/SOCKS5, повтор загрузки при обрыве сети и журнал действий.

## Сборки

Вкладка «Сборки» показывает установленные версии: дата, размер, число модов, Unity из `.exe`. Сборку можно создать с любым названием, переименовать, открыть в проводнике, запустить и удалить. Выбранная сборка используется каталогом для проверки совместимости и установки модов.

## Каталог YanMod

Источник — репозиторий [`bylka882-png/YanMod`](https://github.com/bylka882-png/YanMod). Мод — это папка с `info.yaml`; скриншоты `.webp`/`.gif` лежат рядом. Список файлов берётся из `index.yaml`, иначе из GitHub Tree API, при исчерпании лимита — из jsDelivr. Кэш каталога живёт 6 часов. В окне мода доступен исходный `info.yaml`.

Поля манифеста:

| Поле | Назначение |
| --- | --- |
| `id`, `name`, `by`, `credits` | Идентификатор, название, автор и ссылки; варианты с одним `id` собираются в одну карточку |
| `v` | Версия мода |
| `gameV` | Совместимость: `U19`, `>=U17`, `<=U20`, `2019.07.01`, период `2017.10.04-2019.07.01` или `own` |
| `DL_url` | Ссылка на архив; пустое значение — карточка «Скоро». Тома 7z перечисляются через `;`: `…/Mod.7z.001; Mod.7z.002; Mod.7z.003` |
| `type` | `PM`, `Build`, `TR`, `ML`, `Mod`, `Plugin`, `Translate`; можно не заполнять — тип берётся из папки |
| `cfg` | Путь к конфигу от папки сборки, например `BepInEx\config\BepInEx.cfg` |
| `dependencies` | Зависимости в формате `"id; версия"`; без версии лаунчер подберёт совместимую со сборкой |
| `ioa` | Только для `Build`: моды, уже входящие в сборку (`"PoseMod; 5"`), — строка «В этой сборке установлены» в карточке |
| `affected_files` | Файлы, которые заменяет мод |

Обложка берётся по приоритету: скриншот `1.webp` → превью первого видео из описания → иконка `ico.webp` (квадратная, в левом нижнем углу обложки).

## Конфиги

Редактор открывает INI-подобные файлы установленных модов: `BepInEx/*.cfg`, `AutoTranslator/Config.ini`, настройки Pose Mod и другие. Значения `true`/`false` показываются переключателями, `Acceptable values` — выпадающим списком, цвета — свотчами, клавиши — кнопками с захватом нажатия. Для известных конфигов переведены названия и описания параметров.

Кнопка «Текстовый режим» показывает файл целиком для ручной правки. Оба режима меняют только значения: комментарии, пустые строки и порядок сохраняются.

## Данные

Корневой каталог задаётся в настройках (по умолчанию `%LOCALAPPDATA%\YanLan`):

```
YanLan/
├─ games/          сборки; в каждой лежит .yanlan.json
├─ downloads/      скачанные архивы, если включено их сохранение
├─ cache/          каталог версий и модов, обложки
└─ library.json    установленные моды
```

Настройки лаунчера хранятся в `%APPDATA%\YanLan\config.json`.

## Сборка

Нужны Rust 1.93+ с toolchain MSVC и WebView2 Runtime (входит в Windows 10/11).

```powershell
cargo build --release
```

Готовый файл — `target\release\YanLan.exe`. RAR читается через `unrar`, 7z — через `sevenz-rust2`, ZIP — через `zip`; внешние DLL не нужны. YouTube открывается во встроенном WebView2.
