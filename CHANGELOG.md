# Changelog

Все заметные изменения в проекте **YanLan**. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

Проект начался 28.10.2026. Первая версия, объявленная в `Cargo.toml`, — 1.3.0; записи 1.0.0–1.2.0 — ретроспективная разметка ранних этапов, добавленная вместе с первым CHANGELOG. Версии 1.7.0–1.9.4 не выпускались: после 1.6.0 версия была вручную поднята до 1.9.5.

## [2.2.5] — 2026-11-11

### Исправлено
- Атомарная запись `library.json`, `.yanlan.json`, `config.json`, кэшей каталогов и конфигов модов: обрыв процесса больше не оставляет обрезанный файл.
- Параллельные задачи не теряют записи библиотеки: изменения идут под общим мьютексом, лок не держится во время скачивания и распаковки.
- Битый `library.json` откладывается как `library.json.broken-<время>` вместо молчаливой потери данных.
- Установка сборки откатывается при ошибке, а архив без файлов игры отвергается.
- Корень игры ищется до 4 уровней вложенности, а не до 2.
- У каждой установки свой staging-каталог: параллельные установки в одну сборку больше не мешают друг другу.
- Многотомные архивы и их `.part`-хвосты убираются при ошибке; при отмене тома сохраняются для докачки.
- Если запись мода не сохранилась, уже установленные файлы откатываются.
- Удаление сборки: сначала удаляется папка, затем записи библиотеки — пути к бэкапам не теряются.
- HTTP-агент переиспользуется между запросами; смена прокси сбрасывает старые соединения.
- Параллельные задачи встают в очередь и получают статус-бар по завершении текущей; показывается «+N в фоне».
- Настройки модов: путь не может выйти за папку сборки, пробел после `:` и `=` сохраняется как в исходном файле.
- Ошибки чтения манифестов и зеркал сборок пишутся в лог, а не теряются при частичной загрузке.
- Нераспознанная обложка помечается и не скачивается заново при каждом запуске.
- Локальный сервер плеера отдаёт 404 на все пути, кроме страницы iframe.

### Проверки
- `cargo fmt --all`, `cargo test` — 46 passed, 1 ignored.
- `cargo build --release` — успешно.

### Проверки

- `cargo build --release` — успешно.

## [2.2.0] — 2026-11-10

### Добавлено
- Текстовый режим редактора конфигов и поиск по параметрам; переключение между визуальным и текстовым видом.
- Просмотр исходного `info.yaml` в окне мода.
- Кнопки установки зависимостей и установка мода сразу со всем списком; зависимости видны в окне мода.

## [2.1.5] — 2026-11-10

### Исправлено
- Распаковка 7z переведена с `zesven` на `sevenz-rust2`: один последовательный проход вместо повторного декодирования solid-блока на каждую запись.
- Распаковка ChristmasParty: было ~80 часов, стало 30.6 секунды; 6.38 ГБ, 1823 файла.
- Добавлены прогресс по байтам и файлам, отмена между чанками, проверка путей и обработка пустых файлов.
- `zesven` остался только dev-dependency для тестов; в релиз не попадает.

### Проверки
- `cargo test` — 38 passed, 1 ignored.
- Регрессионный тест: solid-7z из нескольких файлов, включая пустой.
- `cargo build --release` — успешно.

## [2.1.0] — 2026-11-09

### Добавлено
- Установленный мод: кнопка «Установлено» вместо повторной установки.
- Многотомные архивы: `DL_url` через `;`, тома скачиваются по порядку и склеиваются.
- Обложки: `1.webp` → превью первого видео из описания → `ico.webp`; иконка рисуется в левом нижнем углу обложки.
- До 10 видео из описания.
- `ioa` у сборок: моды, уже входящие в сборку, показываются в «Установлено» без кнопки удаления.
- Зависимости `id; v` и предупреждение о недостающих модах.
- Настройка Pose-конфигов: `PoseMod/Settings.ini` и `StreamingAssets/PoseMod/Settings.txt`.
- Захват клавиши в конфиге, RGB/RGBA-свотчи для цветов, русские подписи параметров.
- Шестерёнка настроек только у модов с `cfg`.
- Выбранный язык влияет на редактор конфигов.
- Скругление превью как у карточки.

### Исправлено
- YouTube: локальный HTTP-сервер отдаёт iframe с настоящим Referer — ошибка 153 устранена.
