# Changelog

Все заметные изменения в проекте **YanLan** документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [2.1.5]

### Removed
- Убрана подсветка при наведении: фон и рамка больше не меняются. Розовая рамка осталась только у выбранной сборки. Курсор-рука при наведении сохраняется.

## [2.1.0]

### Added
- Захват клавиши в Pose-редакторе проверен вживую: F9 → клик → F5 → отображается `F5`.
- Регрессионный тест: solid-7z из нескольких файлов, включая пустой.

### Changed
- `extract_7z` переведён на `sevenz-rust2`: один последовательный проход по архиву, включая BCJ2 (используется в CPM).
- Собственный цикл распаковки: `safe_relative` от выхода за каталог, прогресс по байтам/файлам, отмена между чанками, пустые файлы и вложенные папки.
- `zesven` остался только dev-dependency для тестов; в релиз не попадает.
- Время распаковки: было ~80 часов, стало **30.6 секунды**; 6.38 ГБ распаковано, 1823 файла / 5.94 ГБ на диске — совпадает с ручной распаковкой 7-Zip.
- `README.md` обновлён: 7z теперь через `sevenz-rust2`.

### Fixed
- Конфиг Pose-редактора не сохранён (`PosingMenu:F9` остался прежним).
- `library.json` восстановлен: первым снова `BepinX`, 10 модов.

### Tests
- `cargo test`: **38 passed**, 1 ignored.
- `cargo build --release`: собирается, бинарник обновлён.

## [2.0.0]

### Added
- Pose-редактор: русские подписи («Цвет интерфейса», «Меню позирования», «Консоль» и т.д.).
- Цвета — RGB/RGBA-свотчи с корректными значениями (`0.62,0,0,1`, `1,1,1,1`, `0.88,0.5,0.8,1`).
- Клавиши — кнопки (F9, F10, F11, F12).
- Захват клавиши: кнопка заменяется на «Нажмите клавишу… (Esc — отмена)».

## [1.9.0]

### Added
- Каталог YanMod: 8 модов, разделы, поиск, сортировка, совместимость с выбранной сборкой.
- Установка `PoseMod` из каталога в отдельную тестовую сборку: скачался архив, распаковалось 244 файла; в `library.json` появилась запись с категорией `ML`; в карточке появился тег «установлен».
- Окно деталей: компактное, без лишней пустой области.

### Fixed
- Удаление мода: файлы и запись библиотеки корректно откатились.
- Кнопка «Скоро» и заблокированная установка для модов без `DL_url` работают.
- Тестовая сборка `ZTest` удалена, скачанный архив убран.
- Сборки «Основа» и `Oka's Horror Story Remake` и их моды не тронуты — библиотека вернулась к исходным двум записям `BepinX`.

### Tests
- `cargo fmt` выполнен, `cargo test` — 26 passed, 1 ignored, `cargo build --release` — успешно.

## [1.8.0]

### Added
- Загрузка списка манифестов → парсинг YAML → группировка по `id` → варианты по `gameV`.
- Вкладка «Каталог»: сетка карточек с превью, поиск, фильтры по типу, переключатель «только совместимые», кнопка установки в текущую сборку.
- Установка: скачивание в `downloads/` (докачка, прогресс, прокси) → `installer::install_mod` → запись в `library.json` → бэкапы/удаление.
- Кэш каталога в `cache/`, офлайн-фолбэк, кнопка «Обновить».
- Поддержка `serde_yaml` и `.webp` в `image`.

### Changed
- `gameV`: `<=…` / `>=…`, период `yyyy.mm.dd-yyyy.mm.dd`, Unity `U4/U5/U17/U19/U20/U6`, `own`.
- `description`: строго `RU|EN`.
- `type`: `Mod`, `PM`, `TR`, `ML`, `Build`, `Plugin`, `Translate`.
- Проверка совместимости: `GameInstall.meta.date` + `unity_label()` (реальный Unity из exe, иначе по дате). Сборки без даты — «совместимость неизвестна».
- `description` делится по `|` с фолбэком на имеющуюся половину; `by`/`credits` — автор и ссылка.
- `type: Build` — готовая сборка, ставится через `install_game`, а не в текущую сборку.
- Логика совместимости: `U4…U6` сравнивается с Unity сборки; `<=дата` / `>=дата` — с `meta.date`; период — вхождение даты в интервал; `own` — совместимость не проверяется; при нехватке данных — «неизвестно», но мод показывается.

### Notes
- **`index.yaml` в корне репозитория** (рекомендуется): один запрос, кэшируется, нет лимитов.
- Альтернативы: GitHub Tree API (1 запрос на дерево, лимит 60/час на IP), jsDelivr API (без лимита, кэш с задержкой).
- **NewUniforms** — релиз на 16.9 МБ есть, а манифеста в дереве нет, мод не появится. Нужна папка с `info.yaml`.
- **BepInEx** — заполнить `type: ML` и `DL_url`, иначе он навсегда «скоро».
- **Beedrops** и **`build/*`** — заполнить манифесты или оставить как «скоро». У `80sStudentCouncil` уже лежит архив на 1.8 ГБ, но манифест пустой.
- **Скриншоты** — `1.webp`, `2.webp` рядом с `info.yaml`.

## [1.5.0]

### Added
- Выбор сборки кликом по всей карточке — кнопка «Выбрать» убрана.
- `⚙` открывает «Параметры запуска».
- У скачанных сборок показывается Unity из exe: `Unity 6`, `Unity 2020.3.13`, `Unity 2019.3.7`.
- В меню создания у версий есть поколение Unity.
- Поддержка SOCKS (`socks5://`) для прокси.
- Карточка «СЕТЬ» с прокси и бесконечным переподключением.

### Changed
- Текст в полях ввода выровнен по центру по Y (проверено по пикселям).
- Тег «Мод» — компактный прямоугольник, «Удалить» в строке мода выровнена по центру.
- Во время скачивания удаление сборок и установка модов больше не блокируются, задачи идут параллельно.
- Уведомления во время задачи поднимаются над увеличенным статус-баром (102 px).
- В статус-баре отображается `v1.5.0`.

### Tests
- `cargo fmt --check` чистый, `cargo test` — 19/19, release-сборка успешна.
- `CHANGELOG.md` дополнен секцией 1.5.0.
- Тестовый каталог удалён, `%APPDATA%\YanLan\config.json` восстановлен.

- В карточке мода справа зарезервирована ширина под «Удалить», длинные имя/автор обрезаются с `…`.

- Теги в светлой теме стали контрастнее (серый «Другое» больше не сливается).
- Очень длинные названия сборок обрезаются в карточках и в верхнем списке, а не выдавливают кнопки.
- Подзаголовок вкладки: «Моды во всех сборках — по секции на сборку».
- `CHANGELOG.md` обновлён.

## [1.0.0]

### Added
- Реальный bootstrap: `eframe::run_native`, окно 1200×800, иконка-сердце, `windows_subsystem = "windows"` в release.
- Вкладка «Установлено»: карточки сборок (Играть / Папка / Выбрать / Удалить, размер, дата, число модов), список установленных модов с откатом, установка локального архива (zip/rar), пустые состояния.
- `README.md`, `.gitignore`.
- `App::root_input`, `delete_game_now`, `ConfirmAction::UninstallMod { key, name, game_id }` — удаление мода теперь всегда попадает в свою сборку.
- `jobs.rs` — событие `ThumbFailed`, чтобы не висели вечные «…» при битых превью.
- UI: сетка карточек модов теперь режется на ряды (не вылезает за край), счётчик сборок перенесён из перегруженного тулбара, читаемый текст у неактивной кнопки в светлой теме.

### Fixed
- `net.rs` — обработка HTTP 416 при докачке (файл уже скачан целиком).
- `builds.rs` — исправлен regex с look-ahead (не поддерживается `regex`), каст `mtime`.
- `installer.rs` — API `unrar 0.5.8` (`entry.filename` — поле), добавлены тесты установки/откатов и поиска корня игры.
- `theme.rs` — подключён `seguisym.ttf` как fallback, иначе иконки ◆ ▤ ☰ были «квадратиками»; убрана зависимость `persistence` (она сбрасывала кастомные стили и вызывала панику `Name("tiny")`).

### Tests
- `cargo build` и `cargo build --release` — **0 предупреждений**, бинарник `target\release\yanlan.exe` ≈ 9,3 МБ, запускается.
- `cargo test` — 9 тестов, все проходят (парсинг дат сборок, безопасные пути, распаковка ZIP → установка мода → восстановление файлов, поиск корня игры).
- Живые скриншоты всех вкладок: загрузились 617 сборок с archive.org, 21 мод с превью GameBanana, работают тёмная и светлая темы, библиотека с тестовой сборкой и модами отображается корректно.
